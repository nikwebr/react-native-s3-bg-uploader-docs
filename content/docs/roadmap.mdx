---
title: Roadmap
---

1. Preserve files on iOS and Android after app restarts so that they do not need to be selected again
2. Provide additional parameter for uploadFile to influence the hash in case of an hash conflict
3. Handling of expired files (e.g. via getUploadUrls or when a part upload fails)
4. Cancel backend API call to also signal cancellations to the backend
5. Chunkwise encryption before upload
